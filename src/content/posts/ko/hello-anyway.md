AI가 코드를 써 주고, 설명도 해 주는 시대입니다. 그래도 직접 코드를 읽고, 실행하고, 왜 그렇게 동작하는지 이해하고 싶습니다.

이곳은 그 과정을 쌓아 두는 작은 노트입니다.

## 무엇을 기록할까

- **커널** — 작은 함수에서 시작해서 시스템의 동작까지 따라가기
- **AI** — 도구를 사용하는 것을 넘어 원리를 실험하기
- **하드웨어** — 코드와 실제 장치가 만나는 지점 살펴보기

완성된 답뿐 아니라 막혔던 지점과 생각이 바뀐 순간도 남기려 합니다.

## 작은 시작

```c
#include <stdio.h>

int main(void)
{
    puts("Understand it anyway.");
    return 0;
}
```

> AI가 할 수 있어도, 나는 어쨌든 직접 이해하고 싶다.

이 글은 시작을 위한 예제입니다. 앞으로 나만의 기록으로 채워 갑니다.
